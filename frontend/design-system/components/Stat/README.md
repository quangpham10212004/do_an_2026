# Stat

A labelled figure at the top of a dashboard, earnings or admin page.

- Group 2–4 `Stat`s in one `Stats` strip (a single card split by hairlines), not separate cards.
- Values use the mono numeric style; keep units in the value (đ, %). `hint` adds one line of context.
- Only use when the figures are what the page is about.

Consumer provides: `label`, `value`, `hint`.
