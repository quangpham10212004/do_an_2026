# Avatar

Represents a person by photo or initials.

- Initials come from the last two words of the Vietnamese full name (Nguyễn Minh Anh → MA).
- `sm` 28px in the top bar and dense rows, `md` 36px in lists, `lg` 56px in profile headers, `xl` 80px on a mentor profile.
- Always next to the person's name; the avatar itself is hidden from screen readers.

Consumer provides: `name`, optional `src`, `size`.
