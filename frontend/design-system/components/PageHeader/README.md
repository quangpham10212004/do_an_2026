# PageHeader

The first element of every signed-in page.

- `title` is the page or object name (title-1). `description` says in one sentence what the page is for or the object's key facts.
- `back` (link + label) on detail pages, pointing at the parent list.
- `actions`: at most one primary plus one or two secondary buttons.

Consumer provides: `title`, `description`, `back`, `actions`.
